# Koleksi Playlist Lagu Romantis

Proyek sederhana berupa pemutar musik berbasis web yang menampilkan koleksi lagu-lagu romantis. Proyek ini dibuat menggunakan HTML, CSS, dan JavaScript murni untuk memberikan pengalaman mendengarkan musik langsung di peramban (browser) tanpa memerlukan instalasi yang rumit.

## 🌟 Fitur Utama

* **Pemutar Audio Dasar:** Memutar, menjeda, dan mengulang lagu.
* **Navigasi Playlist:** Fitur untuk melompat ke lagu berikutnya dan sebelumnya.
* **Informasi Lagu:** Menampilkan judul lagu, artis, dan gambar sampul (cover) yang sesuai.
* **Antarmuka Responsif:** Desain yang menyesuaikan di berbagai ukuran layar (desktop dan mobile).
* **Progress Bar Interaktif:** Menampilkan durasi lagu yang sedang diputar dan dapat digunakan untuk *seek* (meloncat waktu lagu).

## 🛠 Teknologi yang Digunakan

* **HTML5:** Struktur dasar dan elemen audio.
* **CSS3:** Styling antarmuka, termasuk transisi dan layout.
* **JavaScript (Vanilla JS):** Logika inti untuk mengontrol pemutaran musik dan manipulasi DOM.

## ⚙️ Prasyarat Instalasi

Anda hanya memerlukan peramban web modern (seperti Chrome, Firefox, Edge, atau Safari) untuk menjalankan proyek ini. Tidak ada *server* khusus atau *database* yang dibutuhkan.

## 🚀 Cara Menggunakan

1.  **Clone Repositori:**
    ```bash
    git clone https://github.com/Choirullamri05/playlist-Lagu-romantis.git
    ```
2.  **Akses File:**
    Buka folder proyek yang telah di-*clone* atau di-*download*.
3.  **Jalankan Aplikasi:**
    Klik dua kali pada file `index.html` atau buka file tersebut menggunakan peramban web pilihan Anda.
    ```
    file:///path/to/playlist-lagu-romantis/index.html
    ```
4.  **Kontrol Pemutaran:**
    Gunakan tombol-tombol yang tersedia di antarmuka (Play/Pause, Next, Previous) untuk mengontrol musik.
